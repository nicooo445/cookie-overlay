# Cookie Overlay

Cookie Overlay is a Minecraft Forge 1.8.9 mod I'm developing for Hypixel Bed Wars.

It adds a customizable TAB overlay that displays player statistics like Bed Wars stars, FKDR, wins, losses and player tags.

I'm currently testing it with a small group of friends and working on improving its performance, customization and reliability.

Cookie Overlay uses the Hypixel API to retrieve player statistics. Requests are handled through a separate backend to keep the API key private and reduce unnecessary requests through caching.

This is currently a personal development project and isn't being sold or monetized.

Cookie Overlay is an independent project and is not affiliated with Hypixel.
