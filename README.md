# Cookie Overlay

Cookie Overlay is a Minecraft Forge 1.8.9 mod I've been working on for Hypixel Bed Wars. I started making it because I wanted a cleaner way to see player stats without having to look everyone up separately.

The main feature is a custom TAB overlay that shows stats like FKDR, Bed Wars stars, wins, losses and player tags. I've also been adding more customization so people can change how everything looks.

## Features

- Custom Bed Wars TAB overlay
- Bed Wars stars and prestige colors
- FKDR, wins and losses
- Player heads and team layouts
- Player tags
- Custom fonts and colors
- Different layouts and settings
- Optional custom Minecraft main menu

## How I Use the Hypixel API

I use the Hypixel API to get player stats for the overlay. The mod has a separate backend that handles the requests and caches the results so it doesn't have to keep requesting the same stats over and over.

I've also been working on improving how it handles rate limits, errors and connection issues.
